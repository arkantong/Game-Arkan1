# TDM Tebak Makna — Android alpha

[Download TDM Tebak Makna 2.0.0-alpha.1](https://github.com/arkantong/Game-Arkan1/raw/refs/heads/main/downloads/TDM-Tebak-Makna-2.0.0-alpha.1.apk)

An offline picture-word puzzle game with 24 puzzles, three chapters, hints, coins, stars, saved progress, and 780 bilingual vocabulary entries.

This development APK uses a debug signing key. Package: `id.meruya.tdm.visual`. It installs alongside the original TDM app without migrating progress.

Game logic and browser interactions were tested. APK signatures were verified; runtime on an Android phone or emulator has not yet been tested.
